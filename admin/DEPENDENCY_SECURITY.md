# Admin dependency security policy

The HQ and venue-operations portal is a Next.js application and must keep dependency security checks separate from feature/UI redesign work.

## Current policy

- `next` must remain on a security-supported patched release. The current 15.5 line has a minimum repository floor of `15.5.24`.
- Admin Portal CI runs `npm audit --audit-level=high` before the production build and Playwright browser QA.
- A high or critical audit finding blocks the admin quality gate until it is reviewed and resolved or explicitly documented with a narrow, justified exception.
- Do not downgrade Next.js or suppress audit findings merely to make CI green.
- Dependency upgrades must preserve the accepted HQ and Venue Manager / Operator browser suites.

The repository currently has no committed npm lockfile. `npm install` therefore resolves versions allowed by `package.json` during CI. If a lockfile is introduced later, it must be generated by npm from an intentional dependency install and reviewed with the same audit/build/browser gates; do not hand-author one.
